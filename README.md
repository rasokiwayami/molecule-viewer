# てのひら分子

名前を入れると分子が立体で現れ、カメラにかざした手でつまんで回せるWebアプリです。40種の分子を内蔵しています。

## 使い方

- 下の一覧から選ぶか、名前を入力してEnterを押します。対応ブラウザではマイクのボタンから声でも入力できます。
- ドラッグ（指1本）で回転、ホイール（指2本）で拡大します。原子を押すと元素名が出ます。ダブルクリックで向きと大きさが戻ります。
- 「手で動かす」を押してカメラを許可すると、片手でつまんで回転、両手でつまんで拡大できます。
- QRのボタンで、同じ分子をスマホで開くためのコードを表示します。

| キー | 動作 |
|---|---|
| `←` `→` | 前後の分子 |
| `/` | 名前の入力 |
| `H` | 手の操作の開始・終了 |

`?m=water` のようにURLで最初の分子を指定できます。

## 開発

Node.js 22以上で動かします。

```sh
npm install
npm run dev      # 開発用サーバー
npm test         # 単体試験
npm run build    # dist/ に出力
npm run e2e      # ブラウザでの通し試験（ビルド後に実行）
```

`dist/` をそのまま静的ホスティングに置けば動きます。カメラとオフライン保存にはHTTPS（手元ではlocalhost）が必要です。

内蔵する分子は `scripts/fetch_molecules.py` と `scripts/make_fullerene.py` で取得・生成します。案内文と手の認識のしきい値は `src/config.js` にあります。

## 制約

- 一度開いたあとは、通信がなくても内蔵の40種を表示できます。手の認識に使うファイル（約37MB）は、初めて「手で動かす」を押したときに読み込みます。
- 内蔵にない名前はWikidataとPubChemで探します。立体構造のデータがない物質（塩、金属を含む化合物、大きな分子など）は表示できません。
- 球の大きさと色は見やすさを優先した模型です。

## データとライセンス

構造・分子式・分子量は [PubChem](https://pubchem.ncbi.nlm.nih.gov/) から取得しました。フラーレンC60の座標は計算で生成しています。
